# outputs/intermediate/kndvi/

Download `kndvi.nc` from the Zenodo archive
(https://doi.org/10.5281/zenodo.20252053) and place it in this directory.

kNDVI resampled to the GLEAM 0.1° grid. Read by the correlation, variance
partitioning and vegetation-mask steps, and used as the target-grid template by
the ERA5-Land branch.
